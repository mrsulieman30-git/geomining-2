# Enterprise Mining, Geological Services, Projects & Laboratory Management Platform

## Project Stack
- **Backend:** Laravel 11.x, PHP 8.3+, MySQL 8
- **Frontend:** Vue 3 Composition API, TypeScript, Inertia.js, Vite, Tailwind CSS
- **Features:** Enterprise CRM, LIMS, HR, Procurement, Finance, Role Based Access Control (RBAC), multi-lingual (EN, AR, SO)

## Setup
1. Clone the repository
2. `composer install`
3. `npm install`
4. Copy `.env.example` to `.env` and set up the database.
5. Run `php artisan migrate`
6. Build frontend: `npm run build` or `npm run dev`
7. Start server: `php artisan serve`
